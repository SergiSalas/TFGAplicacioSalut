## 🌟 Project Overview
This project is a **mobile and web application** designed to **improve users' well-being** by tracking and organizing healthy habits such as **sleep, hydration, and physical activity**.  

✨ It offers a **personalized, engaging, and accessible experience**, leveraging **gamification** and **wearable device integration** to encourage healthier lifestyles.  

---

## 🎯 Main Objectives
✔️ Promote healthy routines (sleep, activity, hydration).  
✔️ Deliver an **intuitive and user-friendly interface**.  
✔️ Integrate with **Google Fit, Samsung Health Connect, Apple HealthKit**.  
✔️ Guarantee **data privacy & GDPR compliance**.  
✔️ Provide **tracking, analysis, and motivation tools**.  

---

## ⚙️ Key Features
- 🏃 **Activity Tracking** → steps, calories, distance.  
- 😴 **Sleep Monitoring** → duration, quality, and cycles.  
- 💧 **Hydration Log** → reminders and water intake stats.  
- 📊 **Data Visualization** → interactive graphs (daily, weekly, monthly).  
- 🏆 **Gamification** → challenges, achievements, and rewards.  
- 👤 **User Profile** → personalized goals and preferences.  

---

## 🛠️ Tech Stack
- **Frontend** → React Native  
- **Backend** → Spring Boot (Java)  
- **Database** → PostgreSQL  
- **Design & UX** → Figma  
- **Integrations** → Google Fit, Samsung Health Connect, Apple HealthKit *(planned)*  
- **Deployment** → AWS *(future iterations)*  

---

## 🚀 Installation & Execution

### 📌 Requirements
- Node.js and npm/yarn  
- JDK 11+ and Spring Boot  
- PostgreSQL running  
- Android Emulator or physical device  

### ⚡ Steps
```bash
# Clone repository
git clone https://github.com/SergiSalas/TFGAplicacioSalut.git

# Frontend setup
cd frontend
npm install
npm start

# Backend setup
cd backend
./mvnw spring-boot:run
```

- Individuals with **specific wellness goals**.

## 🌟 Descripción del Proyecto 
Este proyecto es una **aplicación móvil y web** diseñada para **mejorar el bienestar de los usuarios** mediante el seguimiento y la organización de hábitos saludables como **el sueño, la hidratación y la actividad física**.  

✨ Ofrece una **experiencia personalizada, atractiva y accesible**, combinando **gamificación** e **integración con dispositivos wearables** para fomentar estilos de vida más saludables.

## 🎯 Objetivos Principales 
✔️ Promover rutinas saludables (sueño, actividad, hidratación). 
✔️ Ofrecer una interfaz intuitiva y fácil de usar. 
✔️ Integrarse con Google Fit, Samsung Health Connect, Apple HealthKit. 
✔️ Garantizar la privacidad de datos y cumplimiento del RGPD. 
✔️ Proporcionar herramientas de seguimiento, análisis y motivación. 

---

## ⚙️ Funcionalidades Clave 
- 🏃 **Seguimiento de Actividad** → pasos, calorías, distancia.
- 😴 **Control del Sueño** → duración, calidad y fases. 
- 💧 **Registro de Hidratación** → recordatorios y estadísticas. 
- 📊 **Visualización de Datos** → gráficas interactivas (diarias, semanales, mensuales). 
- 🏆 **Gamificación** → retos, logros y recompensas. 
- 👤 **Perfil de Usuario** → objetivos y preferencias personalizadas. 

---

## 🛠️ Tecnologías 
- **Frontend** → React Native 
- **Backend** → Spring Boot (Java) 
- **Base de datos** → PostgreSQL 
- **Diseño & UX** → Figma 
- **Integraciones** → Google Fit, Samsung Health Connect, Apple HealthKit (futuro) 
- **Despliegue** → AWS (futuras iteraciones)
