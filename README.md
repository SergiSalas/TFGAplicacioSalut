---

## 🌟 Project Overview
This project consists of the development of a **mobile and web application** aimed at **improving users' well-being** through the monitoring and organization of healthy habits such as **sleep, hydration, and physical activity**.  

The app provides a **personalized and accessible experience**, encouraging healthier lifestyles by combining **advanced functionalities, gamification, and wearable integration**.  

---

## 🎯 Main Objectives
- Promote healthy routines (sleep, activity, hydration).  
- Offer an **intuitive, inclusive, and user-friendly interface**.  
- Integrate with external services such as **Google Fit, Samsung Health Connect, and Apple HealthKit**.  
- Ensure **data security and GDPR compliance**.  
- Provide tools for **tracking, analysis, and motivation** to improve quality of life.  

---

## ⚙️ Key Features
- 🏃 **Physical activity tracking**: steps, calories, distance.  
- 😴 **Sleep monitoring**: sleep duration, quality, and cycles.  
- 💧 **Hydration log**: water intake reminders and statistics.  
- 📊 **Trends visualization**: interactive graphs (daily, weekly, monthly).  
- 🏆 **Gamification**: challenges, progress, and rewards.  
- 👤 **User profile**: personal settings, goals, and customization.  

---

## 🛠️ Tech Stack
- **Frontend**: React Native  
- **Backend**: Spring Boot (Java)  
- **Database**: PostgreSQL  
- **Design & UX**: Figma  
- **Integrations**: Google Fit, Samsung Health Connect, Apple HealthKit (future)  
- **Deployment**: AWS (planned for future iterations)  

---

## 🚀 Installation & Execution

### Requirements
- Node.js and npm/yarn  
- JDK 11+ and Spring Boot
